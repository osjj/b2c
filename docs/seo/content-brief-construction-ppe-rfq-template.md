# Content Brief: Construction PPE RFQ Template

## Decision

Create an indexable HTML download landing page for the existing RFQ asset. Do not write it as a long generic blog article.

Recommended URL:

`/downloads/construction-ppe-rfq-template`

Existing asset to keep:

`/downloads/construction-ppe-rfq-template.pdf`

Reason: the site already has the PDF asset, and several existing pages link directly to it. A landing page can capture search traffic, explain when to use the template, preserve the PDF download, and move qualified buyers toward `/quote` without competing with the existing bulk procurement guide.

## Search Intent

Primary intent:

The searcher wants a practical request-for-quote template for buying PPE in bulk for construction work. They are likely trying to send the same scope, quantities, standards, sizes, documentation requests, and delivery requirements to multiple suppliers.

Observed SERP pattern:

- General RFQ template pages rank for broad RFQ queries.
- Construction-specific RFQ/RFI pages are common, but many results are about construction project RFIs, bid forms, or contractor quotes rather than PPE procurement.
- There is a long-tail gap for a PPE-specific construction RFQ template.

Intent classification:

- Commercial investigation
- Procurement execution
- Download/template intent

This page should not read like a safety article. It should help the buyer complete an RFQ faster.

## Keywords

Primary keyword:

`construction PPE RFQ template`

Secondary keywords:

- `PPE RFQ template`
- `construction PPE request for quote`
- `bulk PPE quote template`
- `construction safety equipment RFQ`
- `PPE supplier quote template`
- `construction PPE procurement template`

Avoid targeting as primary:

- `buy construction PPE in bulk`
- `construction PPE checklist`
- `contractor PPE kit checklist`
- `construction RFQ template`
- `construction RFI template`

Those either belong to existing pages or are too broad for the PPE-specific opportunity.

## Cannibalization Check

### `/blog/bulk-construction-ppe-procurement`

Risk: medium if the new page becomes a full buying guide.

Resolution:

Keep the RFQ template page focused on the executable RFQ format. Link to the bulk procurement guide for strategy, supplier comparison, and full purchase planning.

Positioning:

- Bulk procurement guide = how to buy construction PPE in bulk.
- RFQ template page = the form and fields to send suppliers after the buying scope is clear.

### `/blog/construction-ppe-checklist`

Risk: low.

Resolution:

The checklist answers what PPE workers need on site. The RFQ template converts that checklist into supplier quote requirements.

Positioning:

- Checklist = field and supervisor verification.
- RFQ template = procurement document.

### `/blog/contractor-ppe-kit-checklist`

Risk: low to medium because it already has a "Contractor PPE Kit RFQ Template" section.

Resolution:

Keep the contractor-kit article's RFQ section as a short teaser. Link it to the new template page for the full downloadable template.

Positioning:

- Contractor kit page = how to build kit packages.
- RFQ template page = reusable supplier quote format for kits and mixed PPE orders.

### `/quote`

Risk: none.

Resolution:

The quote page is the conversion endpoint. The RFQ template page should send qualified users there with a source-tagged CTA.

### Direct PDF URL

Risk: medium.

Search engines can index PDFs, but a PDF is a weaker conversion surface than an HTML page. Once the landing page exists, internal links should point to `/downloads/construction-ppe-rfq-template` first, with the PDF as the primary download button.

## Recommended Page Type

Download/resource landing page with a short supporting guide.

Not recommended:

- Long blog post
- Generic construction RFQ article
- Duplicate PDF-only page
- Broad procurement guide

## Content Structure

### 1. Hero

Purpose:

Give the user the download immediately and explain what the template solves.

Include:

- H1
- 2-sentence intent match
- Primary download CTA
- Secondary quote CTA
- Small proof line: standards, quantities, sizes, supplier documents, delivery

### 2. What this RFQ template includes

Keep this scannable. Use a table.

Fields:

- Project/site name
- Delivery country or target market
- Worker roles and trades
- PPE categories
- Required standards
- Quantities and replacement stock
- Size ranges
- Branding, packaging, and labeling
- Sample and certification document requests
- Lead time, MOQ, and quote validity

### 3. When to use this template

Use cases:

- Bulk construction PPE order
- Contractor kit sourcing
- New jobsite setup
- Replacement stock planning
- Supplier comparison
- Export order with standards and delivery requirements

Avoid writing a broad "how to buy PPE" guide here. Link to the bulk procurement guide for that.

### 4. PPE categories covered

Use a compact matrix:

- Head protection
- Eye and face protection
- Hand protection
- Safety footwear
- High-visibility clothing
- Respiratory protection
- Hearing protection
- Fall protection
- Weather or heat-stress add-ons where relevant

### 5. Supplier response checklist

This is the section that makes the page commercially valuable.

Ask suppliers to return:

- Unit price and price breaks
- MOQ
- Lead time
- Sample availability
- Product data sheets
- Certificates, approvals, or declarations
- Marking or label photos
- Packaging format
- Carton labeling
- Size replenishment support
- Substitution rules
- Quote validity period

### 6. Copy/paste RFQ email

Add a short email block the buyer can copy.

Purpose:

This matches template intent and makes the page useful even before the PDF download.

### 7. How to use it with Laifappe tools

Keep this short:

- Use PPE calculator to estimate quantities.
- Use AI quote tool to turn scope into RFQ wording.
- Use size guide for safety footwear size planning.
- Use compliance checker for footwear label codes.

### 8. FAQ

Only include visible FAQs if FAQ schema is added.

Recommended FAQs:

1. What is a construction PPE RFQ?
2. What should be included in a PPE RFQ template?
3. Is this different from a construction RFI?
4. Can I use this template for contractor PPE kits?
5. Should standards be listed in the RFQ?
6. Can I send this template to Laifappe for a quote?

## Schema Recommendation

Use:

- `BreadcrumbList`
- `WebPage`
- `FAQPage` only if the FAQ questions are visible on the page

Do not rely on `Article` unless the implementation uses the blog CMS route.

## Implementation Notes

1. Build the HTML landing page first.
2. Keep the existing PDF unchanged for now.
3. Change internal links from the highest-value pages to the HTML landing page.
4. Keep a direct PDF download button on the landing page.
5. Track source:
   - `source=construction-ppe-rfq-template`
   - `data-download-asset="construction-ppe-rfq-template"`
   - `data-download-source="construction-ppe-rfq-template"`
6. Do not mark this as a normal article in navigation copy. Label it as a template or download.

## Do Not Include

- A long explanation of all PPE standards.
- A full "how to buy PPE in bulk" guide.
- A complete contractor PPE kit guide.
- A broad construction quote template unrelated to PPE.
- A generic RFI explanation beyond a short RFQ vs RFI clarification.

## Success Criteria

Before publishing:

- The page has one clear primary keyword.
- The first screen offers the template download.
- The page links to quote with a source parameter.
- The page does not duplicate the bulk procurement guide.
- All FAQ schema questions are visible.
- PDF download clicks can be attributed.
- Internal links from current RFQ mentions point to the HTML landing page.

After publishing:

- Submit the HTML URL for crawling.
- Check whether Google chooses the HTML page or the PDF for the target query.
- Watch queries containing `rfq`, `quote template`, `ppe template`, and `construction ppe`.
- If the PDF begins ranking instead of the HTML page, consider controlling PDF indexation/canonical behavior at the server/header level.
